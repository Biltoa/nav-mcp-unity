NAV MCP — EXACT-SOURCE LOGO KIT
=================================

Fidelity promise
----------------
This kit was built from the supplied 1536 x 1024 PNG. The artwork was not
regenerated, redrawn, font-matched, vector-traced, or recolored.

The files in 01_EXACT_MASTERS ending in _Exact_Black.png are direct pixel
crops from the supplied image. Verification confirms that every RGB pixel
matches the corresponding source rectangle exactly.

Important source limitation
---------------------------
The supplied PNG is RGB on a black background and has no alpha channel.
Therefore, a mathematically original transparent logo does not exist in
the source. The transparent files are carefully derived from the source
against black without changing the contours or inventing new artwork.
For absolute source fidelity, use the _Exact_Black.png masters.

Canonical artwork mapping
-------------------------
- Horizontal assets use the exact upper NAV MCP lockup.
- Mark/app-icon assets use the exact standalone lower mark.
- The two marks were not substituted for one another.
- SVG files are wrappers that embed the exact transparent PNG master.
  They are intentionally not vector traces, because tracing can alter shape.

Folder guide
------------

01_EXACT_MASTERS                Direct black crops + transparent derivatives
02_HORIZONTAL_PNG               Horizontal lockup at common widths

05_FAVICON_AND_WEB              Web/favicon sizes
06_SVG_WRAPPERS_PIXEL_EXACT     Embedded-raster SVG wrappers
VERIFICATION.json               Bounds, hashes, and pixel-match checks
